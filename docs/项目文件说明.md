# 项目文件说明

> 本项目基于 AnomalyCLIP（ICLR 2024）零样本异常检测框架，原作者通过 **DPAM 双路径注意力机制** + **Deep Prompt Learning** 实现了跨域零样本异常检测。我的工作在此基础上引入 **LoRA 少样本微调** 提升特定场景精度，并集成 **YOLOv8 目标定位** 构建了完整的机械臂智能分拣系统。

## 1. 核心算法层（AnomalyCLIP_lib/ - 原作者）

这是整个项目的算法基石，必须优先理解。

| 文件 | 作用 | 重要性 |
|------|------|--------|
| [AnomalyCLIP_lib/AnomalyCLIP.py](../AnomalyCLIP_lib/AnomalyCLIP.py) | **DPAM 双路径注意力 + 深度提示学习的 ViT 视觉编码器**。核心类：`VisionTransformer`（含 `DAPM_replace()` 将顶层 20 层 self-attention 替换为 v-v attention）、`Attention`（同时计算原始 self-attention 和 v-v attention）、`ResidualAttentionBlock_learnable_token`（在 Transformer 每层注入可学习文本 token）。这是整个系统最关键的模型结构文件。 | ★★★★★ |
| [AnomalyCLIP_lib/CLIP.py](../AnomalyCLIP_lib/CLIP.py) | 原始 CLIP 模型实现（ViT-B/ViT-L），包含标准 `VisionTransformer`、`Transformer`、`CLIP` 类。当不启用 DPAM/prompt learning 时使用。 | ★★★ |
| [AnomalyCLIP_lib/model_load.py](../AnomalyCLIP_lib/model_load.py) | 模型加载 + 相似度计算核心。`load()` 下载/加载 ViT-L/14@336px 预训练权重并构建模型；`compute_similarity()` 计算 patch token 与文本特征余弦相似度；`get_similarity_map()` 将一维 token 相似度 reshape 为二维空间热力图。**注意**：第 38 行缓存路径硬编码，本地使用需修改。 | ★★★★★ |
| [AnomalyCLIP_lib/build_model.py](../AnomalyCLIP_lib/build_model.py) | 模型工厂函数。根据是否传入 `design_details` 参数决定构建 `AnomalyCLIP`（含 DPAM+prompt）还是原始 `CLIP`。 | ★★★★ |
| [AnomalyCLIP_lib/constants.py](../AnomalyCLIP_lib/constants.py) | CLIP 官方图像归一化参数：`OPENAI_DATASET_MEAN` 和 `OPENAI_DATASET_STD`。 | ★★★ |
| [AnomalyCLIP_lib/transform.py](../AnomalyCLIP_lib/transform.py) | CLIP 官方图像预处理变换（Resize → CenterCrop → ToTensor → Normalize）。 | ★★★ |

## 2. 根目录共享模块

这些模块被 training/、inference/、sorting_system/ 中的脚本共同引用。

| 文件 | 作用 | 重要性 |
|------|------|--------|
| [prompt_ensemble.py](../prompt_ensemble.py) | **Prompt Learner 定义**。`AnomalyCLIP_PromptLearner` 类：生成 object-agnostic 的可学习文本提示向量。核心输出：`prompts`（输入层 token）、`tokenized_prompts`（BPE token）、`compound_prompts_text`（深层注入 token，深度由 `--depth` 控制）。 | ★★★★★ |
| [loss.py](../loss.py) | FocalLoss（α=0.25, γ=2，聚焦难分类像素）和 BinaryDiceLoss（优化 mask IoU 重叠度）。 | ★★★★ |
| [metrics.py](../metrics.py) | 评估指标：`image_level_metrics()`（AUROC/AP）、`pixel_level_metrics()`（AUROC/AUPRO）。 | ★★★★ |
| [dataset.py](../dataset.py) | 数据加载器。从 `meta.json` 读取数据集索引，支持 20+ 数据集。 | ★★★★ |
| [utils.py](../utils.py) | 工具函数：`get_transform()` 构建图像预处理 pipeline，`normalize()` 做 min-max 归一化。 | ★★★ |
| [visualization.py](../visualization.py) | 结果可视化：将异常热力图叠加到原图生成彩色标注图（JET colormap）。 | ★★★ |
| [logger.py](../logger.py) | 日志工具，同时输出到文件和控制台。 | ★★ |
| [sampler.py](../sampler.py) | **平衡少样本采样器**。`get_balanced_few_shot_indices()` 按 1:1 比例采样 Normal/Abnormal 样本，优先选择带掩码的异常样本。 | ★★★★ |

## 3. LoRA 少样本微调（training/ - 我的核心改进）

| [training/threshold.py](../training/threshold.py) | **基于 Precision-Recall 曲线自动寻找最佳分类阈值**。训练过程中计算每个 epoch 的 F1 最优阈值。 | ★★★★ |

## 4. YOLOv8 定位 + AnomalyCLIP 识别集成（sorting_system/ - 我的核心集成工作）

将 YOLOv8（Stage 1 目标定位）与 LoRA 微调后的 AnomalyCLIP（Stage 2 异常识别）级联，构建端到端的智能分拣系统。

| 文件 | 作用 | 重要性 |
|------|------|--------|
| [sorting_system/auto_sorting_system.py](../sorting_system/auto_sorting_system.py) | **完整分拣系统主程序（PyQt5 UI + AI 推理 + 机械臂控制一体化）**。`AnomalyDetector`（加载 YOLO + LoRA-AnomalyCLIP）→ `DetectorThread`（摄像头采集 + 目标检测 + 异常判定）→ `RobotActionThread`（IK 逆解 + S-Curve 轨迹规划 + UDP 指令）。支持实时热力图叠加、阈值动态调整。**最终产物**。 | ★★★★★ |
| [sorting_system/yolo_train.py](../sorting_system/yolo_train.py) | **YOLOv8 目标定位模型训练**。使用 YOLOv8n 预训练模型，epochs=50, imgsz=640, augment=True。输出 `best.pt`。 | ★★★★ |

## 9. 端到端推理链路

```
摄像头采集 (1280×720)
    │
    ▼
YOLOv8 目标定位 (sorting_system/yolo_train.py → best.pt)
    │ 输出: 边界框 (x1,y1,x2,y2)
    ▼
ROI 裁剪 + padding (10px)
    │
    ▼
AnomalyCLIP + LoRA 异常检测 (training/train_lora.py → best_lora + best_model.pth)
    │
    ├─ Resize(518) → ToTensor → Normalize
    ├─ ViT-L/14 + DAPM 编码 → image_feat + patch_feat
    ├─ text_feat (PromptLearner) × image_feat → 异常分数 (0~1)
    └─ patch_feat × text_feat → 高斯滤波 → 像素级热力图
    │
    ▼
判定: score > threshold ? "NG" : "OK"
    │
    ▼ (if NG)
机械臂抓取: 像素→世界坐标 → IK 逆解 → S-Curve 轨迹 → UDP 指令 → ESP32 执行
    │
    ▼
搬运至废料区 (8.0, -15.7, 7.1) → 释放 → 复位
```
