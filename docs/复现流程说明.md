## 第二步：数据准备

### 2.1 数据集目录结构

以 Pokerback（扑克牌背面）为例：

```
Pokerback/
├── card/
│   ├── train/
│   │   ├── good/          # 正常样本（如 card_001.jpg, card_002.jpg ...）
│   │   └── rotten/        # 异常样本（如有瑕疵的卡牌）
```

### 2.2 标注异常掩码（仅异常样本需要）

1. 用 **LabelMe** 标注异常区域（多边形标注）
2. 运行 `data_tools/mask_product.py` 将 JSON 标注转为掩码 PNG：
   ```bash

   # json_dir = "你的JSON文件夹路径"
   # save_dir = "保存掩码的文件夹路径"
   python data_tools/mask_product.py
   ```

### 2.3 生成数据集索引文件（meta.json）


## 第四步：LoRA 少样本微调（核心步骤）

### 4.1 训练 LoRA + Prompt 联合微调

```bash
python training/train_lora.py \
    --train_data_path ./Pokerback \
    --save_path ./checkpoint_lora_pokerback \
    --checkpoint_path ./checkpoints/9_12_4_multiscale/epoch_15.pth \
    --dataset Pokerback \
    --k_shot 26 \
    --lora_r 8 \
    --lora_alpha 16 \
    --epoch 30 \
    --learning_rate 0.001
```

**参数调优建议**：

| 参数 | 推荐范围 | 说明 |
|------|----------|------|
| `--k_shot` | 10-200 | 少样本数量。数据分布简单的场景 16-26 就够，复杂的需要 100+ |
| `--lora_r` | 4-16 | LoRA 秩，越大模型容量越大但容易过拟合少样本 |
| `--lora_alpha` | 8-32 | 通常设为 `r × 2` 或 `= r` |
| `--learning_rate` | 0.001-0.01 | 如果 loss 不下降，尝试提高到 0.01 |
| `--epoch` | 15-70 | 数据越少 epoch 需要越多 |

### 4.2 消融实验：仅训练视觉端 LoRA（冻结 PromptLearner）

```bash
python training/train_only_visual.py \
    --train_data_path ./Pokerback \
    --save_path ./checkpoint_visual_only \
    --checkpoint_path ./checkpoints/9_12_4_multiscale/epoch_15.pth \
    --dataset Pokerback \
    --k_shot 26 \
    --lora_r 16 \
    --epoch 30
```

### 4.3 自动寻找最佳阈值（训练时同步计算）

```bash
python training/threshold.py \
    --train_data_path ./Pokerback \
    --save_path ./checkpoint_threshold \
    --checkpoint_path ./checkpoints/9_12_4_multiscale/epoch_15.pth \
    --dataset Pokerback \
    --k_shot 26 \
    --epoch 30
```

## 第六步：知识蒸馏（边缘部署，可选）

### 6.2 蒸馏训练

```bash

# 或手动

    --train_data_path ./SDD --save_path ./checkpoint_distill_sdd \
```

### 6.4 蒸馏结果（SDD）

| 模型 | Pixel AUROC | Pixel AUPRO | Image AUROC | Image AP | 参数量 |
|------|:-----------:|:-----------:|:-----------:|:--------:|:------:|
| 教师 ViT-L | 90.7 | 81.4 | 87.5 | 86.2 | 304M |
| 学生 ViT-B | 87.2 | 62.3 | 73.6 | 61.2 | 86M |

### 6.5 蒸馏参数调优

| 参数 | 推荐范围 | 说明 |
|------|----------|------|
| `--image_size` | 224-336 | 学生输入分辨率，越高像素定位越精细但训练越慢 |
| `--student_dpam_layer` | 8-12 | DAPM 层数，全 12 层效果最好 |
| `--distill_temperature` | 1.0-4.0 | KL 温度，越低分布越尖锐信号越强 |
| `--lambda_sim` | 10.0-50.0 | 相似度图 KL 蒸馏权重，应 > λ_task |
| `--lambda_task` | 0.5-2.0 | 任务损失权重，仅做辅助正则 |

## 常见问题排查

### Q1: CUDA out of memory

- 减小 batch_size（训练：`--batch_size 4`）
- 减小 image_size（测试：`--image_size 336`）

### Q2: Loss 不下降，一直震荡

- 调高学习率（`--learning_rate 0.01`）
- 检查数据是否正确加载（查看 sampler 输出的 Normal/Abnormal 样本数）
- 增加 k_shot 数量

### Q3: 加载 LoRA 权重时报错 "size mismatch"

- 确认 DAPM_replace 在 LoRA 包装之前执行
- 确认使用了相同的 `--features_list` 和 `--depth` 参数
- 检查 `target_modules` 是否匹配（查看训练时的 print 输出）

### Q4: 模型加载路径错误

修改 `AnomalyCLIP_lib/model_load.py` 第 38 行的硬编码路径：
```python
# 原："/remote-home/iot_zhouqihang/root/.cache/clip"
# 改为本地路径或使用默认缓存
"~/.cache/clip"  # Linux
os.path.expanduser("~/.cache/clip")  # 跨平台
```

### Q5: 蒸馏训练报 "element 0 of tensors does not require grad"

- 确认 `AnomalyCLIP_lib/AnomalyCLIP.py` 中 `VisionTransformer.forward` 的 `@torch.no_grad()` 已移除
- 确认 `ResidualAttentionBlock.forward` 中的 `+=` 已改为 `= ... + ...`（out-of-place）

### Q6: 蒸馏 KL 损失一直接近 0

- 确认使用的是原始 logit（`patch_feat @ text_feat^T / 0.07`）而非 `compute_similarity()` 的结果
- `compute_similarity()` 内部已做 softmax，再 softmax 会压平分布

### Q7: 加载学生 checkpoint 报 "size mismatch for positional_embedding"

- 蒸馏训练时的 `--image_size` 与测试时的 `--image_size` 必须一致
- 如训练用 336，测试也必须用 336

### Q8: 摄像头打不开

运行 `python tools/test_camera.py` 确认摄像头索引和分辨率。
