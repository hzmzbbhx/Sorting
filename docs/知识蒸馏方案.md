# AnomalyCLIP 知识蒸馏方案（边缘部署）

## 背景与动机

AnomalyCLIP 原版视觉编码器为 ViT-L/14@336px，参数量 ~304M，在工业边缘设备（Jetson Orin、树莓派 + 加速棒等）上推理延迟过高。为满足实时检测需求（≥15 FPS），需将模型压缩至 100M 参数以内，同时尽可能保持检测精度。

### 技术路线选择

| 方案 | 压缩率 | 精度保持 | 实现复杂度 | 选用 |
|------|:------:|:------:|:------:|:----:|
| 剪枝 (Pruning) | 2-3× | 中 | 高（需结构化剪枝 + 微调） | ✗ |
| 量化 (Quantization) | 2-4× | 高 | 低（PTQ/QAT） | 可叠加 |
| 轻量架构替换 | 3-5× | 低（从头训练需大量数据） | 低 | ✗ |
| **知识蒸馏** | 3-5× | 中高 | 中 | **✓** |

蒸馏的优势：可利用已有 LoRA 微调教师模型的监督信号，在小样本场景下也能训练学生，与量化可叠加。

## 算法设计

### 教师模型

- 架构：AnomalyCLIP ViT-L/14@336px
- DAPM：layer=20（后 19 层双路径注意力）
- LoRA：r=8, α=16, target_modules=["c_fc","c_proj","qkv","proj"]
- PromptLearner：depth=9, n_ctx=12, t_n_ctx=4
- 输入：518×518，patch 网格 37×37

### 学生模型

- 架构：AnomalyCLIP VisionTransformer ViT-B/16
- 层数/宽度/头数：12/768/12（vs 教师 24/1024/16）
- DAPM：layer=12（全部 11 层，补偿浅层数对异常敏感度的损失）
- 参数：~86M（全参数训练，无 LoRA）
- 输入：336×336，patch 网格 21×21
- 预训练权重：OpenAI ViT-B/16.pt → 按参数名匹配加载 → 位置嵌入 bilinear 插值适配分辨率

### 共享策略

文本编码器（12 层 / 512 宽 / 8 头）+ PromptLearner（~37K 参数）为教师和学生共享，蒸馏期间冻结。CLIP 多模态空间统一投影到 768 维，学生视觉编码器也输出 768 维特征，无需额外投影层。

### 蒸馏损失

```
总损失 = λ_cls × L_cls + λ_sim × L_sim + λ_task × L_task
```

#### 1. CLS 余弦相似度损失（λ_cls=5.0）

```python
loss_cls = (1 - cosine_similarity(student_cls_feat, teacher_cls_feat)).mean()
```

- 对齐全局图像特征方向
- 范围 [0, 2]，信号强度远大于 MSE（MSE 在归一化向量上 ~0.002）
- 教师特征已 L2 归一化（`/ norm(dim=-1, keepdim=True)`）

#### 2. 相似度图 KL 散度（λ_sim=30.0, T=2.0）

```python
# 教师——原始 logit（不做 softmax！）
t_logits = patch_feat @ text_feat^T / 0.07  # [B, N_patches, 2]

# 学生——原始 logit
s_logits = patch_feat @ text_feat^T / 0.07

# KL 散度
t_soft = (t_logits_resized / T).softmax(dim=-1)      # 单次 softmax
s_log_soft = (s_logits / T).log_softmax(dim=-1)
kl = (t_soft * (t_soft.log() - s_log_soft)).sum(dim=-1).mean()
```

**重要**：`AnomalyCLIP_lib.compute_similarity()` 内部做了 softmax，蒸馏必须绕过它直接使用原始 logit。否则 logit → softmax → /T → softmax（二次 softmax）会将分布压平到接近均匀 [0.5, 0.5]，使 KL 散度趋近于 0。

#### 3. 任务损失（λ_task=1.0，辅助正则）

```python
task_loss = FocalLoss(sim_map, gt) + DiceLoss(sim_map, gt) + CrossEntropy(image_probs, label)
```

- 仅起辅助正则作用，防止学生过拟合教师误差
- 权重从原版 λ=4.0 降至 1.0

## 版本迭代过程

### v1：MSE 基线（失败）

- CLS 损失：MSE（~0.003，无意义）
- 异常图损失：MSE（后处理硬图）
- 权重：λ_cls=1.0, λ_patch=0.1, λ_task=4.0
- 结果：像素 AUPRO 34.9，蒸馏信号占 <1%

### v2→v3：余弦 + KL 重构

- CLS 损失：MSE → 余弦相似度（信号强度 ↑200×）
- 异常图损失：MSE → KL 散度（保留 normal/abnormal 分布信息）
- 权重修正：λ_cls=10.0, λ_sim=5.0, λ_task=1.0
- 结果：像素 AUPRO 34.9→51.9，但 sim_loss 仍接近 0

### v4：DAPM 全层 + KL 修正

- 发现二次 softmax bug，修复为单次 softmax
- DAPM：8→12 层（全部双路径注意力）
- 温度：T=4.0→2.0
- λ_sim：5.0→30.0
- 结果：像素 AUROC +8.3, AUPRO +9.4

### v5：提分辨率

- 输入：224→336px（patch 网格 14×14→21×21）
- 批次：4→2（显存适配）
- 结果：像素 AUROC +1.2, Image AP +5.8

## 最终结果（SDD 数据集）

| 模型 | Pixel AUROC | Pixel AUPRO | Image AUROC | Image AP | 参数量 |
|------|:-----------:|:-----------:|:-----------:|:--------:|:------:|
| 教师 ViT-L | 90.7 | 81.4 | 87.5 | 86.2 | 304M |
| 学生 v5 | 87.2 | 62.3 | 73.6 | 61.2 | 86M |
| 差距 | -3.5 | -19.1 | -13.9 | -25.0 | **3.5× 压缩** |

### 分析

- **像素 AUROC**：差距仅 3.5 点，基本满足质量分拣需求
- **像素 AUPRO**：差距 19 点，主要受限于学生 21×21 patch 分辨率（教师 37×37）
- **图像级指标**：差距较大，SDD 仅 16 张训练图，全参数训练存在一定过拟合
- **推理速度**：预期提升 2-3×（待 benchmark 验证）

## 应用场景

1. **边缘端实时质检**：Jetson Orin / AGX 上部署学生模型，实现 ≥15 FPS 推理
2. **多路视频并发**：单 GPU 同时推理多路产线，教师模型显存无法支撑
3. **快速换线适配**：新产线用 LoRA 微调教师 → 蒸馏到学生 → 部署，全流程可自动化
4. **与量化叠加**：学生对 INT8 量化进一步压缩（86M→~22M），可部署到嵌入式 NPU

## 未来改进方向

1. **多尺度特征蒸馏**：在中间层添加可学习投影头，对齐教师-学生 patch token
2. **对抗蒸馏**：引入判别器强制学生生成与教师不可区分的特征
3. **渐进式蒸馏**：教师→ViT-B→ViT-S 逐级压缩
4. **任务相关蒸馏**：仅蒸馏缺陷区域的 patch token，忽略背景
5. **INT8 量化叠加**：蒸馏后进行 PTQ，进一步压缩至 ~22M
