# SDD 知识蒸馏实验结果

## 数据集

- **SDD (Surface Defect Detection)**：1 类（electrical commutators / 换向器）
- 训练集：19 张（9 defect + 10 good），k_shot=16
- 测试集：110 张

## 教师模型

- AnomalyCLIP ViT-L/14@336px + LoRA (r=8, α=16) + DAPM layer=20
- PromptLearner: depth=9, n_ctx=12, t_n_ctx=4
- 输入分辨率：518×518
- 参数量：~304M

## 学生模型

- ViT-B/16（OpenAI 预训练权重初始化）+ DAPM layer=12
- 共享教师 PromptLearner + 文本编码器（冻结）
- 最终配置：336×336 输入，蒸馏温度 T=2.0

## 关键发现

1. **余弦相似度 >> MSE**：CLIP 特征已 L2 归一化，MSE (~0.002) 无法有效衡量方向差异，余弦相似度信号强度提升 ~200 倍
2. **KL 散度必须用原生 logit**：`compute_similarity()` 已含 softmax，蒸馏时再次 softmax（二次 softmax）会将分布压为均匀，KL 趋近于 0
3. **DAPM 全层替代效果显著**：DAPM=8→12（学生全层双路径注意力），Pixel AUPRO +9.4
4. **336px > 224px**：更高 patch 分辨率带来更精细的异常定位（Pixel AUROC +1.2, Image AP +5.8）
